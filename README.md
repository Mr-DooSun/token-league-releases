# Token League

Claude Code·Codex 사용량을 기록하는 데스크톱 앱입니다. 이 저장소는 설치 파일과 릴리스 정보를 배포하며 소스 코드는 포함하지 않습니다.

## 현재 다운로드

[Token League 0.2.2 Beta](https://github.com/Mr-DooSun/token-league-releases/releases/tag/v0.2.2)에서 운영체제에 맞는 파일을 받으세요.

- macOS Apple Silicon (M1 이후): `aarch64-apple-darwin.dmg`
- macOS Intel: `x86_64-apple-darwin.dmg`
- Windows x64: `x86_64-pc-windows-msvc.msi` 또는 `x86_64-pc-windows-msvc-setup.exe`

macOS는 DMG에서 앱을 Applications로 복사해 설치합니다. 파일 무결성은 릴리스에 첨부된 `SHA256SUMS.txt`로 확인할 수 있습니다.

## 베타 안내

현재 버전은 수동 설치용 베타입니다. macOS Developer ID 서명·공증과 Windows 코드 서명은 아직 준비되지 않아 운영체제가 경고하거나 실행을 차단할 수 있습니다. CI에서의 OS별 빌드·테스트와 실제 기기에 설치한 후의 동작 확인은 구분합니다.

개인 로컬 기록을 사용할 수 있습니다. 온라인 가입·로그인과 회사 인증은 운영 설정 준비 중이며, 개인·회사·팀 리그는 이 설정이 완료된 후 이용할 수 있습니다.

베타는 정식 자동 업데이트 채널로 지정하지 않았습니다. 현재 앱의 업데이트 확인은 오류를 표시할 수 있으며 새 베타는 Releases에서 수동 설치하세요. 앱 식별자와 로컬 기록 경로는 유지됩니다.
