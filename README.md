# Token League

Claude Code·Codex 사용량을 기록하고 개인·회사·팀 리그에 참여하는 데스크톱 앱입니다.

이 저장소는 macOS·Windows 설치 파일, 변경 내역과 업데이트 정보를 배포합니다. 소스 코드는 포함하지 않습니다.

## 설치와 업데이트

릴리스가 게시되면 Releases에서 운영체제에 맞는 설치 파일을 다운로드할 수 있습니다.
- macOS Apple Silicon: aarch64-apple-darwin DMG
- macOS Intel: x86_64-apple-darwin DMG
- Windows x64: x86_64-pc-windows-msvc 설치 파일

0.1.0 사용자는 자동 업데이트를 지원하는 버전을 한 번 수동 설치해야 합니다. 0.2.0부터 설정 → 앱 업데이트에서 업데이트를 확인하고 설치 후 재시작할 수 있습니다.

업데이트 도중에도 로컬 기록과 계정별 기록 소유권을 보존합니다. 업데이트 설치 파일은 앱이 가진 공개키로 서명을 검증합니다.

macOS 설치 호환성 문제로 0.2.0 다운로드를 임시 중단했습니다. 배포 서명·공증을 준비한 뒤 새 버전을 제공할 예정입니다.
